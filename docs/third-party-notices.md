# Avisos de terceiros

## GT-1 FxFloorBoard

O catálogo de parâmetros, os endereços, os formatos de patch e partes da conversão SysEx desta aplicação foram portados a partir do **GT-1 FxFloorBoard**, de Colin Willcocks (2007–2026), baseado no GT8FxFloorBoard de Uco Mesdag (2005–2007). Arquivos de referência utilizados: `midi.xml`, `MidiTable.cpp`, `SysxIO.cpp`, `midiIO.cpp`, `sysxWriter.cpp`, `bankTreeList.cpp` e `floorBoardDisplay.cpp`.

Fonte fornecida na conversa: projeto SourceForge `GT-1FxFloorBoard/gt-1_fxfb_source_code_20260405.zip`. O código-fonte declara GNU GPL versão 2 ou posterior e o pacote inclui o texto da GPL versão 3. O projeto distribui seu código derivado sob GNU GPL versão 3 ou posterior; o texto integral está em [`../LICENSE`](../LICENSE).

O `packager/readme.txt` também contém um texto que limita o software a uso não comercial e solicita licença separada para uso comercial. Como essa cláusula aparece junto com a declaração GPL, sua relação precisa de esclarecimento do autor. Este repositório preserva o aviso, não declara autorização para distribuição comercial e recomenda obter confirmação do autor antes de qualquer uso comercial.

O nome BOSS e GT-1 identifica o equipamento suportado. O projeto não é afiliado à Roland/BOSS.
